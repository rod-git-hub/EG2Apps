## Files

| File | What |
|---|---|
| `apps/eg2notes/app.json` | Even's manifest: `net.techdivision.eg2notes`, `permissions: []`, `min_sdk_version` 0.0.16 |
| `apps/eg2notes/index.html` | The page, with the CSP placeholder `%EG2_CSP%` (filled by `packages/shared/build/csp.ts`) |

| `src/notes.ts` | The data model and every edit (plain TypeScript, no browser APIs: tested in Node) |
| `src/glasses.ts` | The glasses screens: the list, a note, the note's text |
| `src/phone.ts` | The phone page: the list, a note, the damaged-data view |
| `src/wordmark-image.ts` | The corner wordmark as a base64 PNG (generated by `scripts/make-icons.mjs`) |
| `src/demo.ts` | Sample notes, **development only** (`?demo`); never in a build |
| `public/icon.png` | Even's 24×24 app icon |

## Data model

One JSON document under the storage key `eg2notes.v1` (also the Export format):

```json
{ "app": "eg2notes", "schema": 1, "notes": [
  { "id": "…", "title": "Groceries", "text": "", "done": false,
    "items": [ { "id": "…", "text": "Milk", "done": false } ] } ] }
```

| Limit | Value | Where |
|---|---|---|
| Notes | 500 | `MAX_NOTES` |
| Checklist items a note | 200 | `MAX_ITEMS` |
| Title, item | 200 characters, one line | `NAME_MAX_CHARS` (shared `doc.ts`) |
| Note text | 10,000 characters | `TEXT_MAX_CHARS` |
| Whole document | warning at 500,000, refused above 1,000,000 characters | `DOC_WARN_CHARS`, `DOC_MAX_CHARS` |

`parseNotes()` checks everything read back (start-up and Import): unknown fields dropped, every text trimmed and
length-checked, ids `[A-Za-z0-9-]{1,64}` (new ones are random UUIDs). If the saved document fails the check, nothing
overwrites it: the phone page shows it read-only so it can be copied (`damaged`).

Other keys: `eg2notes.theme` (`system` / `light` / `dark`), `eg2notes.lists` (`cursor` / `native`).

## Flow

1. `main.ts` waits up to 10 s for Even's bridge; `evenStorageWorks()` writes, reads back and clears a marker. Inside
   the Even app (or the simulator) the app uses Even's storage; in a plain browser it falls back to `localStorage`
   (preview, no glasses).
2. Every edit runs through `edit()` → `changed()`: save (300 ms later, through the bridge queue), `nav.refresh()` (the
   glasses redraw only what changed), `phone.render()`.
3. Leaving (Even's lifecycle events, `visibilitychange`, `pagehide`) flushes the save at once.

## Glasses details

- **List** (`notesList`): header empty (the corner wordmark names the app); rows `□ Title (2/5)`.
- **Note** (`note`): `≡ Note text` (if any), `● Mark note done / open`, a spacer, then the items. `cursorOnly` when it
  has items: a tick changes the rows, and Even's list would jump back to the top. Tap = `toggleItem`; the cursor stays.
- **Note text** (`noteText`): a text page, paged by `textPages()`; the glasses menu acts on the note.
- Glasses menu rows carry a `RowMenu` (`name`, `move`, `remove`, `contains`): see [glasses-menu.md](glasses-menu.md).

## Privacy

Only what the user types is stored; nothing is sent anywhere (no permissions, `connect-src 'none'`). The phone page's
Privacy card says other plugins can read the storage.
