# Settings and Backup (user guide)

At the bottom of each app's phone page. Each app keeps its own settings, on this phone.

<img src="../../img/eg2notes/phone-03-settings.png" alt="Appearance, Glasses lists and the start of Backup" width="260">

## Appearance

**Match phone** (the default: follows your phone's light or dark setting), **Light** or **Dark**. Only the phone
page changes; the glasses always look the same.

## Glasses lists

How lists look on the glasses:

| | Text cursor (recommended) | Even's select box |
|---|---|---|
| Looks like | A `>` in front of the row | A box around the row, drawn by the glasses |
| Long lists | Scroll with the cursor (`▲▼ 5/11` at the bottom) | Up to 20 rows; longer lists 18 at a time, with **▲ Previous** and **▼ More** rows |
| After a change | The cursor stays where it was | The highlight goes back to the top |
| Glasses menu on lists | Yes | No: open an item to use it there |

Checklists and select mode always use the text cursor, so ticking keeps your place. The change shows on the glasses
at once.

<img src="../../img/eg2notes/glasses-04-select-box.png" alt="Even's select box on the glasses" width="480">

## Backup

There's no server and no cloud copy: your phone holds the only copy.

<img src="../../img/eg2notes/phone-04-backup.png" alt="Backup: Export, Check pasted text, Import" width="260">

- **Export:** puts all the app's data in the box as plain text (JSON). Copy it and keep it somewhere safe, for
  example in a file or an email to yourself. While it's on the phone's clipboard, other apps may be able to read it.
- **Check pasted text:** paste an export into the box: it says what it holds ("3 notes with 14 checklist items"), or
  what's wrong with it. Nothing changes yet.
- **Import:** replaces **everything** in the app with the pasted export, after a second tap.

An export from EG2Notes only imports into EG2Notes, and one from EG2Presentation only into EG2Presentation.
The stopwatch and the settings aren't part of an export.

## Privacy

The last card says it once: the app has no internet access, no account, no analytics and no AI; your data stays on
this phone, in storage that other plugins and the Even Realities app itself can read.
