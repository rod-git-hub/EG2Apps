# The glasses menu (user guide)

Even's own menu on the glasses, with the apps' items. **Tap, then press and hold** to open it. It acts on the row
under the `>` cursor, or on the item a text page shows (a note's text, a topic's details).

| Item | Does |
|---|---|
| **Move up** / **Move down** | Moves the row one place; the cursor follows it. Same order on the phone |
| **Select** | Select mode for this list (below) |
| **Delete** | Asks first: "Delete "Groceries"? (9 checklist items will be deleted too) This can't be undone." Tap = delete, double tap = cancel |

On a text page the menu has Move up, Move down and Delete (no Select).

## Select mode

The list shows **■ Delete N selected**, **○ Cancel**, a blank line, then the rows: `★` selected, `☆` not. The row you
started on is already selected.

- Tap a row to select or unselect it.
- **Delete N selected**: one confirmation for all of them (anything inside them goes too).
- **Cancel** or a double tap leaves select mode without deleting.

## Not available

- **With Even's select box** (phone page → Glasses lists), lists have no glasses menu: Even's list doesn't say which
  row is highlighted when the menu opens. Open an item and use the menu there, or switch back to the text cursor.
- **Rename, create and edit** are on the phone only.

There's no undo: every delete asks first, and **Export** on the phone page is the safety net.
